# Dynama Primus Optimizer (P19–P21)

Система для выбора оптимальных решений в финальных периодах DYNAMA:
- цены по моделям
- маркетинговые бюджеты (end-user / retailer)
- микс производства
- расширение мощности (+5k)
- запуск M4

## Быстрый запуск (веб-система)

```bash
cd /home/user/webapp
pip install streamlit pandas
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

После запуска откроется интерактивная система, где команда может:
- запустить оптимизацию одной кнопкой,
- увидеть рекомендации по периодам P19/P20/P21,
- сравнить LOW/MID/HIGH сценарии,
- скачать готовый JSON-план.

## Быстрый запуск (CLI)

```bash
cd /home/user/webapp
python dynama_optimizer.py
```

После CLI-запуска создаётся файл:

- `primus_p19_p21_optimal_plan.json` — рекомендованная стратегия + результаты по сценариям LOW/MID/HIGH.

## Что делает модель

- Проводит стохастический перебор (`60,000` комбинаций стратегий).
- Для каждой стратегии считает финансовый результат в 3 сценариях спроса.
- Оптимизирует ожидаемую финальную Equity с учётом штрафа за риск (плохой downside).

## Важно

Это decision-support модель (для выбора лучшей стратегии), а не официальный движок DYNAMA. Перед отправкой финального решения команда может вручную подкорректировать параметры и перезапустить расчёт.
